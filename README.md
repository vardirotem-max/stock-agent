# סוכן סורק מניות יומי (S&P 500, סווינג)

כל יום אחרי סגירת וול סטריט הסוכן סורק את ה-S&P 500, מוצא מניות במגמה עולה שנסוגו לאזור תמיכה,
ושולח לטלגרם: **Buy Limit / Stop / Target** + כמות מוצעת לפי ניהול סיכון.
הוא גם עוקב אחרי ההמלצות הקודמות (מילוי, יעד, סטופ) ומחשב סטטיסטיקות ב-`signals_log.csv`.

## הקמה (כ-15 דקות)
1. **בוט טלגרם:** בטלגרם דבר עם `@BotFather` ← `/newbot` ← שמור את ה-Token.
2. **Chat ID:** שלח הודעה כלשהי לבוט שיצרת, ופתח בדפדפן:
   `https://api.telegram.org/bot<TOKEN>/getUpdates` ← חפש `"chat":{"id": ...}`.
3. **GitHub:** צור repo פרטי והעלה אליו את כל התיקייה (כולל `.github`).
4. ב-repo: Settings ← Secrets and variables ← Actions ← הוסף
   `TELEGRAM_BOT_TOKEN` ו-`TELEGRAM_CHAT_ID`.
5. Actions ← "Daily stock scan" ← Run workflow, לבדיקה ראשונה.
   משם זה רץ לבד כל יום חול ב-22:30 UTC (אחרי הסגירה; בישראל זה בלילה).

## הרצה מקומית
```
pip install -r requirements.txt
python backtest.py     # בדיקת עבר על 5 שנים - להריץ לפני הכל
python scanner.py      # סריקה (בלי טוקן מדפיס למסך)
```

## כוונון
כל הפרמטרים ב-`config.py`: גודל חשבון, אחוז סיכון לעסקה, RSI, מכפיל ATR לסטופ, יחס סיכוי-סיכון, פילטר שוק ועוד.

## חשוב
- הבדיקה ההיסטורית סובלת מ-survivorship bias, ללא עמלות והחלקות, ולא מדמה מגבלת פוזיציות במקביל.
- הריצו paper trading כמה חודשים לפני כסף אמיתי. זה כלי סינון ולא תחזית. לא ייעוץ השקעות.

## מסחר דמה ב-Alpaca (Paper)
אם מוגדרים הסודות `ALPACA_KEY_ID` ו-`ALPACA_SECRET_KEY` (מפתחות של חשבון Paper בלבד), כל סיגנל נשלח אוטומטית
כהוראת Bracket: קנייה בלימיט + סטופ + יעד. הוראה שלא מתמלאת תוך 5 ימים מבוטלת, ופוזיציה שעברה 20 יום נסגרת.
הכתובת ב-`broker.py` קבועה על חשבון הדמה ואין חיבור למסחר אמיתי.

## דוח יומי ב-20:00 (שעון ישראל)
`daily_report.py` שולח לטלגרם: שווי חשבון, מזומן, רווח/הפסד יומי, פוזיציות פתוחות והוראות קנייה ממתינות.
התזמון רץ פעמיים ביום (17:00 ו-18:00 UTC) והסקריפט שולח רק כשהשעה בישראל היא 20:00, כדי לתמוך בשעון קיץ/חורף.
